# vikarchai.github.io

Developer site for AI Space Tails games, served by GitHub Pages at https://vikarchai.github.io

- `index.html` — game list and support contact (use as the store "Website")
- `privacy.html` — privacy policy for all games (use as the store "Privacy policy URL")
- `app-ads.txt` — AdMob authorised sellers; add the `pub-…` line after AdMob registration
